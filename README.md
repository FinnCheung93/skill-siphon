```text
Skill 吸星大法适合用来研究一个 Skill 的行为设计。
它不会把参考对象机械复制到目标 Skill，而是先理解结构、判断风险，再决定哪些模式值得吸收。
```

## ✨ 它能帮你看什么

- 触发条件是否清楚，是否容易误触发
- 工作流是否顺，是否存在职责重叠
- 规则边界是否稳，是否有越权风险
- 目标 Skill 是否过重、冗余或难维护
- 哪些行为设计值得吸收，哪些应该跳过

## 🧭 适用场景

- 想知道一个 Skill 为什么好用
- 想参考 A Skill 优化 B Skill
- 想审查一个 Skill 的触发、流程和边界
- 想从多个 Skills 里提炼可复用模式
- 想先形成判断，再决定要不要改文件

## 🧩 工作方式

这个 Skill 会先判断当前任务属于哪种情况：

- 只有 source：分析结构与行为模式
- 只有 target：做质量审查与优化建议
- source + target：提炼候选改法，并判断是否采纳
- 明确授权写文件：才进入修改模式，应用已确认的改法

## 🚦 边界

- 不把参考 Skill 机械复制到目标 Skill
- 不在缺少授权时静默修改文件
- 不一次性过度扩写，让目标 Skill 变重
- 不跳过整合检查，避免规则冲突和职责重叠

## 📦 使用方式

把本目录作为 Codex skill 安装或放入你的 skills 目录中，由 Codex 在相关任务中自动触发。

```text
SKILL.md
```
