### ✨ 它能帮你看什么

<sub>不是复制别人的 Skill，而是先分析、再判断，最后才决定是否采纳或改写。</sub>

- 看清触发条件、工作流、边界和风险
- 检查误触发、越权、过重和冗余问题
- 从优秀 Skill 中提炼可复用的行为设计
- 判断哪些改法值得吸收，哪些应该跳过
- 在正式改写前形成采纳清单和执行计划

### 🧭 适用场景

- 研究一个 Skill 为什么好用
- 对比多个 Skills 的行为设计
- 审查目标 Skill 有没有误触发、越权或过重问题
- 参考一个 Skill 优化另一个 Skill
- 在正式改写前先形成清晰判断

### 🧩 工作方式

- 只有 source：分析结构与行为模式
- 只有 target：做质量审查与优化建议
- source + target：提炼候选改法，并判断是否采纳
- 明确授权写文件：才进入修改模式，应用已确认的改法

### 🚦 边界

- 不把参考 Skill 机械复制到目标 Skill
- 不在缺少授权时静默修改文件
- 不一次性过度扩写，让目标 Skill 变重
- 不跳过整合检查，避免规则冲突和职责重叠

### 📦 使用方式

把本目录作为 Codex skill 安装或放入你的 skills 目录中，由 Codex 在相关任务中自动触发。

```text
SKILL.md
```
